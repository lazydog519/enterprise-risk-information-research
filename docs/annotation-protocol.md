# 风险陈述人工核验规则 v1

适用实验：`20261029_paragraph_control_v1`。

## 一条风险相关陈述

原文对某一主体的经营风险条件、不利影响、一般风险暴露关系，或直接对应的应对行动及目标，作出的一项可以单独核验的主要判断。

核验单位是判断，不等于句子、段落、风险标题或一次已发生事件。输入单位保留完整段落及必要标题；一个段落可以包含多条判断。相同主体、关系、条件、时间和状态的改写算重复。同一状态下围绕同一目的的并列措施允许合并。措施与其目标分开判断。仅有风险标题不自动产生一条有证据的事件。

本规则选择纳入措施及目标，是为了保留风险披露的完整表达；不把措施提及视为有效性的证据。来源为公司自述，事实性标签表示原文如何陈述，不证明客观事实。

## 人工核验

先独立读完整来源段落，列出参照判断及证据，再查看模型回答。两位核验者分别工作，分歧讨论后保留原标签与裁决理由。当前助手试读单独标为 assistant_source_review，不充当两人金标准。

|项目|通过标准|错误或分歧记录|
|---|---|---|
|纳入与单位|与经营风险或对应措施、目标直接相关；主要判断可单独核验|无关纳入、拆分过细、合并异质判断、遗漏|
|主体与归属|区分公司、行业、客户、供应商等；继承标题语境须有依据|主体错配、行业判断移给公司|
|关系及条件|保留影响方向、关系对象、否定、条件与目标语气|关系错配、漏条件、目标当成果|
|陈述状态|针对主要判断标注；一般关系的肯定不等于损害已发生|状态错配、主要判断不清导致无法裁决|
|时间|只使用原文对应时间；未说明为null|披露时间冒充事件时间、无依据补时|
|证据|逐字可定位且在语义上支持整项判断|引用不存在、引用存在但不支持、必要上下文不足|
|唯一性|同一判断一次|完全重复与语义重复分开计数|
|上下文|识别输入截断或指代缺失|不完整输入被标成充分，或无依据补全|

状态标签：确定（原文肯定的行动或一般关系）、可能或条件成立（条件后果或尚待实现的计划、目标）、明确否定、无法判断。风险大小另属任务，不从状态标签直接计算。

错误采用多标签，分别记录主体、关系、条件/否定、状态、时间、证据、重复与上下文问题。

## 归因与记录

输入缺少必要内容，记为输入问题；规则允许多种合理解释，记为口径分歧；完整证据与明确规则下仍出现无依据判断，记为模型理解问题。成因可以并存。输出长度失败、字段校验失败与语义错误分别记录。实验设置与结果见 [段落对照](../experiments/20261029-paragraph-control/README.md)。
